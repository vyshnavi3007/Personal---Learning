RAG simulator

Edit the knowledge base, ask a question, and watch each step of retrieval-augmented generation run. Embeddings and the answer are simulated in your browser, so no AI model or internet is needed.

Step 1: Chunk the data Indexing

An LLM cannot read your whole database at once, so the text is cut into small chunks. Small chunks are precise but lose context. Large chunks keep context but add noise.

Step 2: Create vector embeddings Indexing

Each chunk becomes a list of numbers (a vector) that captures its meaning. Similar meanings give similar vectors. Real models use hundreds of numbers. This demo uses 32, shown as bars.

Step 3: Ask a question Querying

Your question is embedded with the same method, so it can be compared with the chunks.

Step 4: Retrieve the top matches Querying

Vector search finds chunks with similar meaning. Text (keyword) search finds exact word matches. Hybrid search blends both. Reranking then re-scores the top results.

Press Run RAG to see results.

Step 5: Augmented prompt and answer Querying

The retrieved chunks are added to your question with instructions. The LLM answers only from that context, which reduces made-up answers.

Press Run RAG to build the prompt.
